# Causal excursion effects for categorical treatments with a binary proximal outcome

Code for the paper *Micro-randomized Trials with Categorical Treatments and Binary
Proximal Outcome: Causal Effect Estimation and Sample Size Calculation*, by Jeremy Lin and
Tianchen Qian. The repository contains an implementation of the proposed estimator and of
the sample size calculator, the code that reproduces the Drink Less data analysis and the
figures of the data example, and the simulation studies reported in the paper and its
supplement.

## Requirements

R (developed under 4.5) with `dplyr`, `ggplot2`, `tidyr`, `rootSolve`, `MASS`, `Matrix`,
`mvtnorm`, `pracma`, `latex2exp`, `metR`, `geepack`, `lme4`, `foreach`, `doParallel`, and
`doRNG`. The report `.Rmd` files additionally use `knitr`, `kableExtra`, `here`,
`gridExtra`, and `ggpubr`.

## Data

The Drink Less data are public and are not redistributed here. Download
`FINAL Dataset_A.rds` from the Drink Less OSF repository, <https://osf.io/w3szp>, and place
it in a `dataset/` folder at the root of this repository (the folder is gitignored), or
point the environment variable `DRINKLESS_DATA` at the file. Everything else in this
repository is generated by the code.

## The two methods

| File | What it implements |
|-|-|
| `functions/wcls_cat_trt_binary_outcome.R` | the proposed estimator, its variance, and the general linear hypothesis machinery: `wcls_categorical_treatment()`, `wcls_summary()`, `wcls_glh()` |
| `functions/ss_calc.R` | the sample size calculator, `mrt_mult_trt_ss()` |
| `functions/utillity.R` | the helpers used to set up a design: `construct_pt()`, `construct_ftgt()`, `construct_taut_theta()`, `solve_alpha()`, `solve_beta()`, `construct_L()` |
| `functions/dgm.R`, `functions/functions_util.R` | generative models and small utilities used by the simulations |
| `misc/toy_example/` | a worked example of the estimator on simulated data |

## Reproducing the paper

**Data example (Section 5).**

| Script | Output |
|-|-|
| `Application/DrinkLess/Data Analysis/prepare_drinkless_data.R` | builds the analysis data set from the OSF file: the decision point index starting at 0, the proximal outcome lagged within participant, the employment indicators, and the AUDIT risk categories |
| `Application/DrinkLess/Data Analysis/reproduce_table2.R` | Table 2, the effect statements in Section 5.1, and the inputs to the sample size illustration in Section 5.2. Runs end to end from the OSF file in about a second |
| `Application/DrinkLess/Data Analysis/gee_comparison.R` | the comparison of the proposed estimator with log-link GEE and with a Poisson mixed model, reported in the response to reviewers |
| `Application/DrinkLess/Sample Size Calculator/regenerate_paper_figures.R` | all seven panels of Figures 1, 2, and 3, written to `figures/`. Computes every grid from scratch and takes about ten seconds |
| `Application/DrinkLess/Data Analysis/DrinkLess_DA.Rmd` | the original exploratory analysis of the trial, kept for reference |

The seven `Application/DrinkLess/Sample Size Calculator/* sensitivity to n` folders hold
the original per-figure pipelines, which were run on a cluster and whose saved grids are
distributed separately. `regenerate_paper_figures.R` supersedes them for reproducing the
published figures.

**Simulations.**

| Folder | What it produces |
|-|-|
| `simulation/consistency_sim/` | the consistency and asymptotic normality simulations of Supplementary Section C, including the comparison with GEE |
| `simulation/power_simulation /` | the sample size formula simulations of Supplementary Section D, one subfolder per working assumption. Each subfolder holds a `sim_code/` directory that runs the Monte Carlo (long: plan on a cluster) and a report `.Rmd` that turns the saved results into the figures |
| `simulation/typeI_error_simulation/` | the type I error rate simulations. Three scripts in this folder still `source()` absolute paths from a developer machine and will not run as they stand |

## Notes

- The simulation report `.Rmd` files read their inputs with `here::here("dataset", ...)`,
  so saved simulation results must sit in the same `dataset/` folder as the trial data.
- `mrt_mult_trt_ss()` takes the randomization probabilities as a `T x (K+1)` matrix whose
  first column is the probability of no treatment. `construct_pt()` builds the ones used
  in the paper, including `"constant p0 high"` for the Drink Less design (0.4, 0.3, 0.3).
