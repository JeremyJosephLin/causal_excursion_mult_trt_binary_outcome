# Causal excursion effects for categorical treatments with a binary proximal outcome

Code for the paper *Micro-randomized Trials with Categorical Treatments and Binary
Proximal Outcome: Causal Effect Estimation and Sample Size Calculation*, by Jeremy Lin and
Tianchen Qian. The repository contains an implementation of the proposed estimator and of
the sample size calculator, the code that reproduces the Drink Less data analysis and the
figures of the data example, and the simulation studies reported in the paper and its
supplement.

## Requirements

R (developed under 4.5) with `dplyr`, `ggplot2`, `tidyr`, `rootSolve`, `MASS`, `Matrix`,
`mvtnorm`, `pracma`, `latex2exp`, `metR`, `geepack`, `lme4`, `foreach`, `doParallel`, and
`doRNG`. The report `.Rmd` files additionally use `knitr`, `kableExtra`, `here`,
`gridExtra`, and `ggpubr`.

## Data

The Drink Less data are public and are not redistributed here. Download
`FINAL Dataset_A.rds` from the Drink Less OSF repository, <https://osf.io/w3szp>, and place
it in a `dataset/` folder at the root of this repository (the folder is gitignored), or
point the environment variable `DRINKLESS_DATA` at the file. Everything else in this
repository is generated by the code.

## The two methods

| File | What it implements |
|-|-|
| `functions/emee_catA.R` | the proposed estimator EMEE-catA and its variance: `emee_catA()` |
| `functions/functions_util.R` | `emee_catA_summary()` for the coefficient table, `emee_catA_glh()` for general linear hypotheses |
| `functions/ss_calc.R` | the sample size calculator, `mrt_mult_trt_ss()` |
| `functions/utillity.R` | the helpers used to set up a design: `construct_pt()`, `construct_ftgt()`, `construct_taut_theta()`, `solve_alpha()`, `solve_beta()`, `construct_L()` |
| `functions/dgm.R`, `functions/dgm_*.R` | the generative models used by the simulations |
| `misc/toy_example/` | a worked example of both methods on simulated data; `Rscript "misc/toy_example/ss_calculator_sample_code.R"` runs it from anywhere |

`emee_catA()` takes `pmatrix_tilde`, a decision points by treatment levels matrix of the
reference probabilities `p~`, with the columns ordered `(0, 1, 2)`. It defaults to `1/3`
per level. The Drink Less scripts set it to the trial's randomization probability
`(0.4, 0.3, 0.3)`, so that `J_t = 1` throughout, which is the choice Section 5.1 of the
paper describes.

## Reproducing the paper

**Data example (Section 5).** Each of these runs end to end from the OSF file.

| Script | Output |
|-|-|
| `Application/DrinkLess/Data Analysis/prepare_drinkless_data.R` | builds the analysis data set from the OSF file: the decision point index starting at 0, the proximal outcome lagged within participant, the employment indicators, and the AUDIT risk categories |
| `Application/DrinkLess/Data Analysis/reproduce_table2.R` | Table 2, the effect statements in Section 5.1, and the inputs to the sample size illustration in Section 5.2. Takes about a second |
| `Application/DrinkLess/Data Analysis/gee_comparison.R` | the comparison of the proposed estimator with log-link GEE and with a Poisson mixed model, reported in the response to reviewers; also checks on these data the equivalence claim of Supplementary Section C |
| `Application/DrinkLess/Data Analysis/gee_comparison_bprime.R` | analysis (b'), the same comparison with the nuisance model deliberately misspecified, also reported in the response |
| `Application/DrinkLess/Sample Size Calculator/regenerate_paper_figures.R` | all seven panels of Figures 1, 2, and 3, written to `figures/`. Computes every grid from scratch and takes about ten seconds |
| `Application/DrinkLess/Data Analysis/DrinkLess_DA.Rmd` | the original exploratory analysis of the trial, kept for reference. Its numbers are not the published ones: it predates the two preprocessing corrections adopted in the revision, which are described in the header of `gee_comparison.R` |

The seven `Application/DrinkLess/Sample Size Calculator/* sensitivity to n` folders hold
the original per-figure pipelines, which were run on a cluster and whose saved grids are
distributed separately. `regenerate_paper_figures.R` supersedes them for reproducing the
published figures.

**Consistency and asymptotic normality (Supplementary Section C).**

```sh
cd simulation/consistency_sim
Rscript run_consistency_sim.R      # 1000 replicates, in parallel; writes results/
Rscript summarize_consistency.R    # prints the three tables and their LaTeX bodies
```

`run_consistency_sim.R` runs all three settings of Section C from one generative model,
`dgm_consistency.R`, which is the model displayed in the supplement. Both scripts take the
replicate count as an optional first argument, so `Rscript run_consistency_sim.R 20 4` is a
quick check. The two `sim_consistency_*` subfolders are the earlier per-scenario cluster
pipelines, kept for the record; they do not reproduce the published tables. See
`simulation/consistency_sim/README.md`.

**Sample size formula simulations (Supplementary Section D).** One folder per working
assumption under `simulation/power_simulation /`. Within a folder,

```sh
Rscript compute_factorial_design.R                      # writes factorial_design.RDS here
Rscript sim_power_<k>.R <isetting> <nsim> <nsetting>    # long: plan on a cluster
```

and the report `.Rmd` turns the saved Monte Carlo results into the figures. These scripts
were written for a cluster and expect to be run from their own folder.

**Type I error simulation.** `simulation/typeI_error_simulation/` has the same two-step
structure and produces the type I error figure of the supplement. Its report `.Rmd` also
sourced a helper file belonging to a different project, which is not part of this
repository; that line is commented out, and the chunks that would have used it are knit
with `eval = FALSE`.

## Notes

- The simulation report `.Rmd` files read their inputs with `here::here("dataset", ...)`,
  so saved simulation results must sit in the same `dataset/` folder as the trial data.
- `mrt_mult_trt_ss()` takes the randomization probabilities as a `T x (K+1)` matrix whose
  first column is the probability of no treatment. `construct_pt()` builds the ones used
  in the paper, including `"constant p0 high"` for the Drink Less design (0.4, 0.3, 0.3).
- The estimator was called `wcls_categorical_treatment()`, in a file named
  `wcls_cat_trt_binary_outcome.R`, in earlier versions of this repository. It is
  `emee_catA()` in `functions/emee_catA.R` throughout now, matching the name the paper
  uses.
